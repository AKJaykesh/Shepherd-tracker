Import a calendar

Choose an .ics file exported from Google Calendar, Apple Calendar, or Outlook. Importing the same file again updates those events instead of duplicating them.

How do I get the file from Google Calendar?

Open calendar.google.com, click the gear, choose Settings, then Import & export, then Export. Google downloads a zip file. Unzip it and pick the .ics file for the calendar you want.
